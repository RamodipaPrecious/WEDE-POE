# THE BEAUTY CLINIC WEBSITE

## 1. Project Overview

The Beauty Clinic website is a multi-page website developed for a professional hair and nail salon based in Polokwane, Limpopo, South Africa.

The purpose of the website is to provide customers with information about the salon, its services, prices, opening hours and contact details. It also allows visitors to explore services, view images, read hair and nail care tips and submit enquiries.

The website was developed using HTML5, CSS3, JavaScript and JSON.

---

## 2. Website Objectives

The main objectives of the website are:

* To introduce The Beauty Clinic to potential customers.
* To provide information about the salon.
* To display available hair and nail services and prices.
* To provide contact information and opening hours.
* To allow customers to submit enquiries.
* To create an easy-to-use navigation system.
* To provide interactive website features.
* To improve the user experience on different devices.
* To apply search engine optimisation techniques.
* To demonstrate HTML5, CSS and JavaScript skills.

---

## 3. Website Pages

The website consists of five main HTML pages.

### Home Page – index.html

Introduces The Beauty Clinic and provides an overview of the salon and its services.

### About Us Page – about.html

Provides information about the salon, including its story, mission, vision and values. It also contains an interactive FAQ section.

### Services Page – services.html

Displays the available hairstyles, nail services, prices and additional services. It includes service searching, category filtering, price sorting, a photo gallery with a lightbox and dynamically loaded hair and nail care tips.

### Contact Page – contact.html

Provides the salon's address, telephone number, email address, opening hours, Google Maps location and contact form.

### Enquiry Page – enquiry.html

Allows customers to submit service enquiries and view estimated service prices.

The improvements include:

* Relevant page titles.
* Meta descriptions and keywords.
* Clear heading structures.

* Search-friendly content.

## 7. Forms and Validation

The website contains contact and enquiry forms.

The forms use appropriate HTML elements, including:

* Text inputs.
* Email inputs.
* Telephone inputs.
* Textareas.
* Select elements where required.
* Submit buttons.

HTML5 validation and JavaScript are used to check user input and provide feedback.

The contact form prepares an email using the mailto functionality, while the enquiry form prepares an email through Gmail.

## 13. How to Run the Website

1. Open the project folder in Visual Studio Code.
2. Install the Live Server extension if it is not already installed.
3. Open the `index.html` file.
4. Right-click the file.
5. Select **Open with Live Server**.
6. The website will open in the default browser.
